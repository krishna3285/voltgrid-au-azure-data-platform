# VoltGrid AU - Azure Data Engineering Platform

An end-to-end, cost-conscious Azure data engineering portfolio project for a fictional Australian EV charging franchise network.

## What this project demonstrates

- Azure Data Lake Storage Gen2 medallion architecture: Bronze, Silver, Gold
- Azure Data Factory batch ingestion
- Azure Databricks PySpark and Delta Lake transformations
- Event Hubs streaming telemetry
- Synapse serverless SQL, Power BI, data quality, monitoring, and security

## Learning journal

Every completed lab is documented in `docs/learning/`, with repeatable portal instructions in `docs/runbooks/` and interview practice in `docs/interview/`.

## Safety rule

This repository contains only synthetic data and secret-free configuration. Do not commit Azure access keys, connection strings, SAS tokens, passwords, API keys, or personal access tokens.
